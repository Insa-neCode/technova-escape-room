# Nachtschicht bei TechNova

Ein digitaler Escape Room zu **linearen Gleichungssystemen** für den Mathematikunterricht (Jahrgang 9/10, NRW).

**Spielen:** https://insa-necode.github.io/technova-escape-room/

## Worum es geht

Samstagabend im Elektronikmarkt TechNova: Das Sicherheitssystem ARGUS hat alle Türen verriegelt. Raum für Raum rechnen sich die Schüler:innen nach draußen und finden heraus, warum ARGUS ausgefallen ist. Spoiler: Es war ein einziges falsches Vorzeichen.

- 7 Räume von linearen Funktionen bis zum Prüfungsstil (Teil A), dazu ein Bonusraum und ein Finale
- Gleichsetzen, Einsetzen, Additionsverfahren, grafisches Lösen, Lösungsvielfalt, Sachaufgaben
- Zahlen werden pro Runde neu erzeugt, Rückmeldungen erkennen typische Fehler (vor allem Vorzeichenfehler)
- Einzelspiel oder Duell zweier Teams an einem Gerät
- Nachweis-Karte mit Prüfcode am Ende

## Für Lehrkräfte

Der Lehrkraft-Modus öffnet sich, wenn man den Titel auf der Startseite etwa 2 Sekunden gedrückt hält (am PC: Strg + Umschalt + L). Dort lassen sich Kurs (E/G), Räume, Zeitlimit, gleiche Zahlen für die ganze Klasse (mit Lösungsblatt), Ton und PIN einstellen und als Klassen-Link teilen. Außerdem gibt es eine Vorschau aller Räume und die Prüfung der Prüfcodes.

Bitte im Lehrkraft-Modus eine eigene PIN setzen und die Klasse über den Klassen-Link spielen lassen.

Das Spiel ist eine einzige HTML-Datei und läuft ohne Server und ohne Anmeldung. Spielstände bleiben nur auf dem jeweiligen Gerät.
